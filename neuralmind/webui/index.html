How to use the Playground

Each creature has a small spiking neural network for a brain. It senses food and hazards, and the group of neurons that fires most decides how it moves. Rewards change the connections, so behaviour can improve over time.

  1. Press Play to start the world.
  2. Click a creature to see its brain and body state on the left.
  3. Pick a scenario under Set up a world and create it.
  4. Use Learning test to check whether training helps.

Restart starts the episode again but keeps what the brains learned. New world builds a fresh world with fresh brains from the current settings.
